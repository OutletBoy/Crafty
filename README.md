# Crafty Remote

A phone controller page for the Storz & Bickel Crafty+, using Web Bluetooth. Open it in Chrome on Android: https://outletboy.github.io/Crafty/

## Strain list credits

The page's built-in strain list (r17 on) is made from:

- [Cannabis Intelligence Database](https://github.com/Shannon-Goddard/ci-strains-pro) by Shannon Goddard, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Changed: cut down to name, effects, flavors and terpenes, free text reduced to a fixed word list, and listings of the same strain merged.
